# beware.dog

Next.js app deployed on Vercel. Pushing to `main` auto-deploys to production
([beware.dog](https://beware.dog)).

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Every push to `main` triggers a Vercel production deploy via the connected Git
integration. Preview deploys are created for other branches and pull requests.
